## 2. 新发现

### D-5（P2，修复方案缺陷）：F-1 伪代码未规定循环相对 skip 分支的位置，naive 集成会破坏续跑语义

- **证据（仿真实证）**：`patched_compare` 若把逐条比对循环写成**无条件执行**（skip 分支只置标志），对「claims 存在 + production 为空」的续跑场景输出：
  `skipped=no_production_gate` **且** `consistent=False`（`missing_production_decision`×N）→ Stage 23 将以 `E23_CLAIM_DRIFT` 阻断合法续跑，回归 `test_stage23_skips_without_production_gate` 与 M5 跳过用例。
- **正确集成（同样仿真实证）**：**保留原守卫**（逐条循环置于 `if claims and not production: skipped` 的 else 分支），duplicate/orphan 两个集合检查**无条件执行**：
  - skip 场景 → `skipped=no_production_gate, consistent=True, diffs=[]`（与现状一致）；
  - 孤儿场景（gate 有 `[a,b]`、claims 只剩 `[a]`）→ `orphan_production_decision` 命中 `c-22222222`；
  - 整删场景 → 孤儿 diff 且**无** `skipped`（F-5 收紧生效）；
  - 重复场景 → `duplicate_claim_id`，且「无 gate + 重复 id」仍能报出重复（否则漏报）。
- **处置**：P-068 实施 F-1 时必须按此集成；报告伪代码需补一句位置说明。
