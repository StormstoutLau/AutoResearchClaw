# 调研：缩进块判定上下文（P-096，收敛 P-095 D-1）

> **Feature**：P-096，修复 [P-095 复评](../../docs/arc-g3-p3-cleanup-review-20261113.md) §3 的 D-1（P3，fail-open 回归）。
> **Spec 步骤**：Step 1-2（T1 修复批）。
> **结论先行**：D-1 的两种形态（列表上下文缺失、tab 不等价）同源于**逐行缩进启发式缺少块级上下文**；CommonMark 的两条规则可直接消解——① 缩进代码块**不得中断段落**；② 缩进代码块内**行首列表标记**按其内容处理，且列表项的 4 空格续行属列表内容。修复面局限在 `_INDENT_CODE_RE` 与 `extract_claim_markers` 状态机（约 20 行），零接口变更。

## 1. 现状与缺陷回源

| # | 形态 | P-095 探针 | 现状 | 期望 |
|---|---|---|---|---|
| D-1a | 4 空格嵌套 bullet | A5 | 真实标记被当代码丢弃 | 提取 |
| D-1a | 4 空格数字列表嵌套 | J8 | 同上 | 提取 |
| D-1a | 悬挂缩进续行（段落换行 4 空格） | A6 | 同上 | 提取 |
| D-1b | tab 缩进代码块内示例 | A1 | 示例标记被提取 | 跳过（tab=4 空格） |
| D-1a 下游 | 未发布 claim 仅在嵌套列表被引用 | K1 | 不报 `unpublished_claim_cited`、trace `ok=True` | 报错并判红 |

## 2. 读码取证（E3）

- `_INDENT_CODE_RE = r"^ {4,}\S"`（[claim_spine.py](../../researchclaw/evidence/claim_spine.py) L33）：只认空格、只认行首缩进、无上下文。
- `extract_claim_markers`（L293-334）：顺序为「空白→围栏→缩进→标题→正文」；`in_indent` 一旦置位只由「低缩进非空行」关闭，**进入条件不看前一非空行**。

## 3. 外部规则回源（T1，CommonMark 0.31.2）

| 规则 | 条文要点 | 对本缺陷的作用 |
|---|---|---|
| Indented code blocks | 「An indented code block cannot interrupt a paragraph.」 | 段落行后紧跟的 4 空格行是**惰性续行**，属正文 → 修 A6 |
| Indented code blocks | 制表符在计算缩进时等价 4 空格 | tab 行应按代码块跳过 → 修 D-1b |
| List items | 列表项内容缩进由标记宽度决定（`- ` = 2），更深缩进为**内容延续**而非代码 | 4 空格嵌套 bullet/数字列表属列表 → 修 A5/J8 |
| Block starts | 缩进代码块可起始于空行后、文档首、或块级构造（标题/围栏）结束后 | 保留既有「伪标题不进正文」「围栏内跳过」语义 |

## 4. 方案对比

| 方案 | 做法 | 取舍 | 判定 |
|---|---|---|---|
| S-1 仅排除列表标记 | 4 空格行以 `-`/`*`/`+`/`1.` 开头则不判代码 | 修 A5/J8，**不修 A6**（悬挂缩进无列表标记），不修 tab | 不足 |
| S-2 仅加「不得中断段落」 | 前一非空行是段落且无空行间隔则视为正文 | 修 A6/A5/J8（列表项同为「非空行」），不修 tab 无列表标记的 tab 缩进嵌套 | 近足 |
| **S-3 = S-2 + tab 等价 + 列表标记排除** | 三规则并用 | 覆盖 A5/J8/A6/A1；实现 ~20 行；单向性可证 | **采纳** |
| S-4 完整 CommonMark 块解析器 | 引入 markdown-it-py 等依赖 | 依赖膨胀、偏离「纯 helper」定位 | 拒绝 |

## 6. 对设计的输入

1. 三条判定并用：**列表标记排除** + **tab 等价** + **不得中断段落**（前一非空行类型判别）。
2. 单向性：新规则只会把「原先跳过的行」重新纳入正文提取（fail-closed 方向），不会新增跳过；tab 行是唯一「新增跳过」，其方向与 P-085 的示例跳过一致。
3. 回归护栏：P-094 全部 6 项用例与 P-085 4 项用例必须零改动通过。
